# シルエット試着（スマホ用ウェブアプリ）

自分の体型の 3D アバターに服を重ね着して、サイズ感と着こなしを確かめるアプリです。
PC の Chrome / Edge 拡張機能「シルエット試着」と、GitHub の非公開リポジトリを通してデータをそろえられます。

- 開く: https://shunautumn.github.io/silhouette-fit-app/
- ホーム画面に追加すると、アプリのように全画面で使えます（iPhone は Safari の共有ボタン →「ホーム画面に追加」）。

人体モデルは [MakeHuman](https://github.com/makehumancommunity/makehuman) の CC0 データを使っています。
